# راهنمای استقرار و پایداری در سرور ایران (DigiWP / WP Claude Bridge)

این سند معماری، نحوه راه‌اندازی، و سازوکار تضمین پایداری سیستم در زمان **قطعی اینترنت بین‌الملل (شبکه ملی اطلاعات / اینترانت داخلی)** روی سرور ایران (مانند `wp.nabuxai.ir`) را تشریح می‌کند.

---

## ۱. معماری سیستم در سرور ایران

استک در محیط ایران روی سرورهای داخلی (نظیر ابر آروان یا دیتاسنترهای داخلی با IP ایران) مستقر می‌شود:

```text
[ کاربر در ایران (اینترانت/ملی) ]
              │
              ▼ (HTTPS - پورت 443)
       ┌───────────────┐
       │ Traefik Proxy │ (پروکسی معکوس Coolify و مدیریت SSL)
       └───────┬───────┘
               │
        ┌──────┴────────────────────────┐
        ▼                               ▼
 ┌─────────────┐                 ┌─────────────┐
 │  digiwp-hub │                 │ digiwp-demo │
 │ (React/Nginx)                 │ (WordPress) │
 └──────┬──────┘                 └─────────────┘
        │ /api/*
        ▼
 ┌───────────────┐
 │ digiwp-server │ (Node.js API & Relay)
 └──────┬────────┘
        │
        ▼
 ┌───────────────┐
 │   digiwp-db   │ (PostgreSQL 16)
 └───────────────┘
```

1. **شبکه یکپارچه و مبدأ واحد (Single Origin):**
   - پنل اصلی روی `https://wp.nabuxai.ir` لود می‌شود.
   - درخواست‌های API از مسیر `https://wp.nabuxai.ir/api/*` مستقیماً توسط Nginx به `digiwp-server:8787/v1/*` روت می‌شوند.
   - نیازی به درگیری با CORS یا دامنه‌های متفرقه نیست.

2. **لایه امنیتی و ارتباط با سایت‌های وردپرسی:**
   - سرور واسط از طریق پروتکل رمزنگاری‌شده **HMAC-SHA256** با افزونهٔ `wp-claude-bridge.php` روی وردپرس صحبت می‌کند.
   - در شرایطی که سرور و وردپرس هر دو در دیتاسنترهای داخل ایران باشند، ارتباط رله بدون ترافیک بین‌الملل و با تأخیر زیر ۲ میلی‌ثانیه انجام می‌شود.

## ۲. راهکارهای تاب‌آوری در قطعی اینترنت بین‌الملل (Zero External Dependency)

هنگام قطع ارتباط بین‌الملل، سیستم با اتکا به قابلیت‌های زیر **بدون کوچکترین اختلال** به کار خود ادامه می‌دهد:

| چالش بالقوه در قطعی نت | راهکار پیاده‌شده در DigiWP |
| :--- | :--- |
| **قفل شدن لود صفحه روی Google Fonts** | فونت استاندارد فارسی **Vazirmatn** مستقیماً در فولدر `/fonts/` فرانت‌اند باندل شده و با `@font-face` محلی در ۰ میلی‌ثانیه لود می‌شود. |
| **عدم دسترسی به OpenAI / Anthropic** | سرور از پارامتر `ASSISTANT_URL` پشتیبانی می‌کند؛ می‌توان آن را به دروازه داخلی نابوگیت (`https://gate.nabuxai.ir/v1`) یا مدل‌های محلی (مانند Ollama یا vLLM روی سرور داخلی) متصل کرد. |
| **نبود هوش مصنوعی خارجی** | در صورت در دسترس نبودن هیچ مدل زبانی، سیستم قوانین قطعی (Deterministic Briefing) و **تمام ۱۵۱ ابزار هوشمند وردپرس** بدون نیاز به LLM و مستقیماً روی سرور و وردپرس اجرا می‌شوند. |
| **عدم دسترسی به api.wordpress.org** | سرور برای استعلام‌های خارجی تایم‌اوت کوتاه دارد و در صورت عدم پاسخ‌دهی، وضعیت صادقانه «عدم دسترسی به اینترنت» را اعلام می‌کند بدون آنکه کانتینر فریز شود. |
| **اسکن بدافزار و پایش امنیتی** | پایگاه داده امضاهای YARA و اطلاعات آسیب‌پذیری‌های CVE در دیتابیس لوکال PostgreSQL ذخیره است و اسکن‌ها به صورت ۱۰۰٪ آفلاین صورت می‌گیرد. |
| **غیرفعال شدن تلگرام** | سامانه‌های ارسال هشدار مالک سایت به درگاه‌های بومی **پیامک ایران (کاوه نگار/فراز اس‌ام‌اس)** و **پوش وب / نجوا (Najva)** مجهز است. |

## ۳. مراحل راه‌اندازی روی سرور ایران

### روش اول: اجرای اسکریپت خودکار دیپلوی

اگر کلید SSH سرور در سیستم شما تعریف شده است (مانند `nabuxir`):

```bash
./deploy/setup-iran.sh nabuxir
```

این اسکریپت فایل‌ها را همگام کرده، متغیرهای `.env` را آماده نموده، ایمیج‌ها را روی سرور بیلد کرده و تست سلامت (`/health`) را انجام می‌دهد.

### روش دوم: اجرای دستی با Docker Compose

۱. اتصال به سرور ایران و رفتن به دایرکتوری پروژه:
```bash
cd /opt/digiwp
```

۲. کپی فایل متغیرهای محیطی و تنظیم مقادیر:
```bash
cp deploy/iran-env.example .env
nano .env
```

۳. بالا آوردن سرویس‌ها:
```bash
docker compose -f docker-compose.iran.yaml up -d --build
```

۴. بررسی وضعیت کانتینرها:
```bash
docker compose -f docker-compose.iran.yaml ps
```

## ۴. تنظیمات DNS برای `wp.nabuxai.ir`

در پنل DNS دامنه (مثل کلودفلر یا ابر آروان):
- یک رکورد **A** برای `wp.nabuxai.ir` به سمت IP سرور ایران (`89.44.240.182`) ایجاد کنید.
- (اختیاری) یک رکورد **A** برای `demo.wp.nabuxai.ir` جهت استفاده از وردپرس آزمایشی به سمت همان IP بسازید.

پروکسی معکوس Traefik موجود روی سرور به‌طور خودکار درخواست‌ها را دریافت کرده و گواهی رایگان SSL لِتس‌انکریپت را صادر می‌نماید.
